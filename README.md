# Campus Lost & Found

A clean, modern, and minimal Lost & Found web application designed specifically for **schools and colleges**.

Built with pure **HTML**, **CSS**, and **JavaScript** — separated cleanly across dedicated files.

## Project Structure

```
├── index.html     # HTML structure for all 5 pages/views
├── style.css      # Clean styling and responsive layout
├── script.js      # Campus location handling, matching algorithm & local storage
├── README.md      # Project documentation
└── .gitignore     # Git ignore rules
```

## Features

- **Campus Location System**: Report lost or found items with Building/Block, Floor, Area type (Lab, Classroom, Library, Canteen, etc.), Room number, and notes.
- **Smart Matching**: Automatically checks descriptions, categories, colors, brands, and campus locations to suggest matches.
- **Browse & Search**: Filter by Lost/Found, Campus Area, or Category with keyword search.
- **Persistent Storage**: Saves data in browser `localStorage` (works completely offline).
- **Responsive**: Clean look on mobile, tablet, and desktop.

## How to Run

Just double-click `index.html` (or open it in any modern browser). No servers or build tools required!
